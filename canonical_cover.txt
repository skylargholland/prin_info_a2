First Normal Form (1NF) Changes

Created ApplicantRace table and removed:
• applicant_race_1
• applicant_race_2
• applicant_race_3
• applicant_race_4
• applicant_race_5

Created CoApplicantRace table and removed:
• co_applicant_race_1
• co_applicant_race_2
• co_applicant_race_3
• co_applicant_race_4
• co_applicant_race_5

Created ApplicationDenialReason table and removed:
• denial_reason_1
• denial_reason_2
• denial_reason_3

Added race_number to ApplicantRace and CoApplicantRace to preserve the original race ordering (1-5).

Added denial_reason_number to ApplicationDenialReason to preserve the original denial reason ordering (1-3).

Repeating groups were removed and replaced with one row per race/denial reason value to satisfy 1NF.

Location

Created location_id as a surrogate primary key for Location.

location_id represents a unique combination of:
• state_code
• county_code
• msamd
• census_tract_number
• population
• minority_population
• hud_median_family_income
• tract_to_msamd_income
• number_of_owner_occupied_units
• number_of_1_to_4_family_units
